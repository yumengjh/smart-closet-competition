# 第一轮衣物分割实验

日期：2026-09-26。平台：macOS arm64、Java 21.0.11，CPU 推理。

## 结论

后端已经打通：上传 → 原图保存 → GrabCut/U²-Net → 蒙版 → 透明 PNG → 裁剪预览 → 重新框选。

**当前只能确认完整平铺浅色上衣这个样例能得到可检查的主体图，尚未证明任意床单场景都能稳定处理。** 通用 U²-Net 在杂物、多件衣物、衣物出画时会选择错误主体或丢失大块衣物。GrabCut 也会严重误分割。接口成功不代表结果合格。

打开 [对比报告](latest/index.html) 或 [对比图](latest/comparison.png) 查看原图与两种结果。格子表示透明区域；原始 PNG 和蒙版保留在每个样例目录中。

## 目视检查

| 样例 | GrabCut | U²-Net | 场景说明 |
| --- | --- | --- | --- |
| white-shirt-light | 主体完整度较好，部分边缘需要细查 | 主体完整度较好，轮廓较连贯 | 唯一完整单件、四周留背景的网上样本；没有人工真值蒙版 |
| white-shirt-wood | 木地板残留，衣服大片丢失 | 主要保留领口附近，衣身缺失 | 图片本身是衣服局部特写，完整衣物没有进入画面；失败样例 |
| yellow-shirt-clutter | 衣服破碎，保留部分杂物 | 植物和水果被保留，衣服大片消失或半透明 | 杂物与衣物相互遮挡，出画；失败样例 |
| clothes-on-bed | 大致保留整组衣物，出画袖子被切掉 | 主要只保留针织背心，外套、短裤丢失 | 多件重叠衣物，超出当前单件范围；失败样例 |

“主体完整度较好”仅为开发时目视判断，不是质量保证。没有标注数据，因此没有报告 IoU、精确率或所谓“识别成功率”。

## 本次完整验证运行的耗时

来自 [latest/results.json](latest/results.json)。单位毫秒，含解码、算法和图片保存，不含上传；同一测试进程中的预热状态会影响数字。这是单次测量，不是 P50/P95 基准。

| 样例 | GrabCut | U²-Net |
| --- | ---: | ---: |
| white-shirt-wood | 12559 | 1119 |
| white-shirt-light | 3841 | 1005 |
| yellow-shirt-clutter | 9420 | 944 |
| clothes-on-bed | 2464 | 1043 |

第一次单独运行图片对比时，U²-Net 首张包含模型加载为 2996 ms，后面三张为 861 / 873 / 657 ms。由此仅能判断这个原型在当前机器上的量级，不能外推到其他服务器。

单独运行图片对比测试进程时，系统 `time -l` 记录最大 resident set size 为 1,760,952,320 字节（约 1.64 GiB）。它包含测试、图片报告生成、JVM 与本地库等开销，不能等同于一次模型推理的净内存。独立 JAR 的实测记录另见 [packaged-smoke.json](packaged-smoke.json)。

## 验证范围

`mvn -Dcloset.samples=true verify`：**17 项测试全部通过，无跳过**。

- OpenCV 本地库实际运行，分离高对比合成衣物并保留领口孔洞。
- 上传实际 EXIF 方向标记的 JPEG，校验纠正后尺寸。
- 蒙版正确改变透明度，保留原有 RGB 像素。
- 损坏图片、像素超限、文件超限、越界/不完整框选、未知方法、未安装模型明确报错。
- 实际 HTTP 上传、元信息读取、图片下载、GrabCut 重新框选。
- 四张网上图片 × 两种方法，保存结果供人工检查。
- U²-Net 重新框选，验证结果仍是原图坐标尺寸、框外透明、框内衣物区域存在。
- 并发忙碌返回 429，前一任务失败后释放处理容量。

常规 `mvn test` 只运行 15 项无需模型的测试，另两项实际模型测试需要显式开启；不会在测试时自动下载模型。

## 下一步实验

1. 补充完整单件衣物在实际床单上的照片：花床单、同色背景、深色衣物、阴影、细肩带等；固定一批不参与调参的对照图。
2. 对失败标明具体原因：衣物缺失、背景残留、细节丢失、多主体选择错误。不要只依据前景面积自动宣布成功。
3. 以相同照片对比更强的分割模型，并单独测量内存和延迟，再决定是否替换 U²-Net。
4. 必要时增加“保留/去除区域”的涂抹修正；当前仅支持矩形框选。

照片来源与许可见 [samples/SOURCES.md](../samples/SOURCES.md)。本轮没有安装 Java 依赖之外的软件，没有调用付费 AI API，没有将本地照片发往远程推理服务。
