### 质量观察

- 单件识别出 T 恤、圆领、短袖、文字与图形印花；品牌、尺码、成分、洗护均未知，没有把印花机构标志误写成品牌。
- 主色在红/橙边界，模型选择橙色。此类颜色受拍摄影响，仍需用户修改；没有声称实物校色正确。
- 模型把圆领 T 恤的门襟标成不适用。随后只增加一条提示词规则：没有前开襟的完整圆领 T 恤应识别为套头。提示词 SHA 随内容变化，之前的成功结果仍对应旧快照。
- 最终版本将识图输入缩到最长 1600 像素并合成白底；缩放、透明处理及 Gemini 请求体通过本地模拟测试。上述两次成功云端样本使用修改前的原尺寸输入。最终提示词及缩放组合尚未取得新的成功云端结果。
- 两张样本仅证明接口和关键分支可用，不代表通用品类准确率、复杂衣标 OCR 或所有场景已经验收。

## 完整云端流程尝试

第三次在同一衣物中请求：识别 → gpt-image-2.5-flare 整理 → 透明处理 → 贴纸。

- 识图返回 HTTP 429，识别步骤 FAILED；工作流继续图片分支。
- 生图返回 HTTP 503，记录 UNKNOWN，后续依赖图片步骤跳过。
- 两个调用均未自动重试，没有更换更贵模型。
- 已有成功识别结果仍保留；手工将主色改成红色、品牌明确清空的操作没有被覆盖；仍只有同一个衣物 ID。
- 因上游失败，**此次完整云端流程未成功**；完整流程的本地模拟集成测试通过。

失败分支记录见 [完整流程尝试](full.json)。上游恢复后，可在衣物档案中主动重新识别或重新整理；这会创建新的调用与历史记录。
