# 智能搭配推荐 P1 实施与验收（2026-10-08）

设计：[智能搭配推荐引擎与语义召回设计](../../docs/design/2026-10-08-智能搭配推荐引擎与语义召回设计.md)。分支：后端与前端均为 `feat/outfit-recommend-v2`，尚未合并到 main。

## 交付内容

| 部分 | 内容 |
|---|---|
| 推荐引擎（`com.smartcloset.recommend`） | 结构化意图、衣物特征层、按位置召回（字段 + 关键词）、结构/冷暖/正式程度硬约束、七维白盒打分、多样化挑选、"新尝试"位、建议外层、模板理由、理由核对 |
| 穿搭画像 | 收藏、已保存搭配、OOTD、反馈、打卡、弱行为信号、长期记忆中明确的颜色喜恶；60 天半衰期、3 条证据门槛、按季节统计 |
| 持久化 | V15：`recommendation_log`（含各维度得分）、`recommendation_feedback`、`style_signal`、`wear_log`、`recommend_setting` |
| 接口 | 推荐、换一批、换一件、采用换件结果、反馈、行为事件、打卡、画像查看与设置（全部零模型调用） |
| 助手 | `recommend_outfits`、`present_outfits`；旧候选三步工具不再提供给模型；系统提示词 v2 |
| 前端 | 助手中的推荐卡片：总分、亮点、提示、标签、"为什么这样搭"得分明细、每件入选原因、建议外层、👍/👎 反馈；行为事件攒批上报 |
| 模板库 | 初稿 58 条，全部待审核，见 [模板库初稿](../../docs/design/2026-10-08-搭配模板库初稿（待审核）.md) |

## 性能

500 件衣柜单次推荐（不含数据库读取）：**86 ms**（召回后 948 种组合全部打分）。设计目标 <500 ms。

## 模型输入对比

同一账号、同一衣柜，旧工具 `get_outfit_candidates` 与新工具 `recommend_outfits` 返回给模型的内容（JSON 字符数）：

| 衣柜件数 | 旧 | 新 | 降幅 |
|---|---|---|---|
| 20 | 30,440 | 1,961 | 94% |
| 60 | 50,883 | 1,954 | 96% |
| 120 | 42,969 | 1,934 | 95% |

此外，模型调用次数从 3 次（取候选 → 搭建 → 回复）降为 2 次（推荐 → 回复）。旧流程中候选结果会在第 2、3 次调用里重复发送，因此整轮输入的实际降幅大于上表。表中是字符数而不是 token 数：本环境没有接入真实模型，无法读取真实用量，上线后可在决策追踪里核对。

## 验收中发现并已修正的问题

| 问题 | 修正 |
|---|---|
| 毛衣配短裤这类上下冷暖不协调的组合排在前列 | 冷暖维度新增上下装保暖差 ≥2.5 的扣分 |
| 12°C 通勤时"新尝试"选出了卫衣配短裤 | 短裤、凉鞋的排除温度从 10°C 提高到 15°C；"新尝试"要求每个维度都不低于 0.6 |
| 通勤推荐的标题显示"休闲" | 标题优先使用与场景一致的共同风格 |
| 👎 反馈弹层无法打开 | 弹层触发器内嵌了提示气泡导致点击被吞，已去掉；`a-checkable-tag` 补充全局注册 |
| 重复提问时每张卡片都出现"近 7 天推荐过"橙色警告 | 新鲜度只影响排序，依据仅在得分明细中显示 |

## 与设计的差异

| 设计 | 实际 | 原因 |
|---|---|---|
| 反馈接口 `POST /api/recommendations/{id}/feedback` | `POST /api/recommendations/logs/{logId}/feedback` | 反馈对象是"展示过的某一套"，用记录 ID 更准确 |
| 特征表为 YAML | `feature-tables.json`、`outfit-templates.json` | 不额外依赖 YAML 解析库，结构与内容不变 |
| 弱信号在页面隐藏时用 `sendBeacon` 发送 | 页面隐藏时立即用普通请求发送 | `sendBeacon` 无法携带 CSRF 头；失败直接丢弃，符合"尽力上报"的定位 |
| 聊天回复整体经过理由核对 | 核对模型通过 `present_outfits` 提交的理由；卡片上的亮点全部来自后端 | 最终回复是流式输出，无法在发出前拦截；卡片内容本身已保证真实 |
| `present_outfits` 可在后续轮次换选 | 仅限同一轮 | 历史消息不携带工具结果，后续轮次拿不到 runId；后续轮次的调整由 P3 的"换一件"按钮完成，同样零模型调用 |
| 模板库约 100 条 | 初稿 58 条 | 先收录判断可靠的部分，审核后再补充 |
