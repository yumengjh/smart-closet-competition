## 最小真实上游验证

使用后端已配置的 yumg 上游，只进行以下两条推理请求，不发送个人衣物。

- `/models` 返回 200、26 个模型，包含 gpt-6-luna。
- Agent：gpt-6-luna，reasoning_effort=none，强制调用无副作用 check_capability；9 个流式分片，工具参数 ok=true。usage 为输入 64、输出 19、总计 83 tokens。
- 识图：gpt-6-luna，现有 RecognitionService、reasoning_effort=low、公开 white-shirt-light.jpg、严格 garment-v2 schema。上游正常结束，16 个字段通过平台校验。最初实测脚本把字段数误写成 17，校验后的断言失败；已改为 RecognitionSchema.FIELDS.size()，避免再次付费，没有重新发送图片。该次 usage 未在断言之前记录。

真实验证只证明此上游的流式工具调用与既有识图结构兼容；搭配推荐的质量没有通过大量真实模型调用评估。
