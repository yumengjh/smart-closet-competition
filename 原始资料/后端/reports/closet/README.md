## 首次登录 403 回归

真实账号首次改密标记尚未完成时，旧前端允许进入业务页并提前查询列表与计数，后端按设计返回 403。已增加全局路由守卫及共享计数检查，首次登录仅显示密码设置；匿名请求、首次改密、CSRF 与一般权限拒绝分别返回明确错误码。

在隔离账号和真实打包页面上验证初始密码登录、直接打开五个业务地址及刷新：改密前业务 API 请求为 0。通过后端接口为测试账号改密后，衣柜 ACTIVE/DRAFT 列表、任务、schema 和额度均返回 200；改密后的浏览器请求全部 200，整个浏览器运行没有 403。真实用户密码未修改。
