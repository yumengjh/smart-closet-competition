# 开放元信息选项验证（2026-09-30）

## 改动

新任务使用 garment-v2：固定 16 项字段以及 values/status/evidence 结构，属性值不再由 enum 限制。常见示例仅为建议；模型及人工可填写浅蓝色、小圆领、针织开衫、刺绣等新名称。旧任务继续使用冻结提示词及 Schema，不自动重跑。

服务端保留数量、长度、空值、字段 key 和状态校验，对有限且明确的同义词归并。动态选项从本人全部 ACTIVE 衣物的有效值聚合，包含人工覆盖和清空语义；草稿、回收站和其他账号不进入词库。浅蓝色、灰蓝色和藏蓝色支持蓝色大类筛选，未覆盖或混合颜色不强制归类。无需数据库迁移。

正式 Vue 页面使用 Ant Design AutoComplete 建议输入、Select tags 多值创建；管理员旧测试页的单选也改为允许新值的建议输入。

## 验证结果

- 前端 `npm test`：14 项通过；`npm run build:server`：类型检查、生产构建与后端静态发布通过。
- 后端 `mvn -q verify`：94 项，89 项通过、5 项可选报告测试跳过，无失败或错误。
- 旧测试页 `node --test src/test/js/*.test.cjs`：3 个测试文件通过。
- Schema 与识别 stub 验证浅蓝色、小圆领等开放值可解析和保存，属性字符串 Schema 不含 enum；非法字段、UNKNOWN 有值、单值超量、超长输出仍被拒绝。
- 仓储回归验证完整数据分页外的新值、账号隔离、人工替换/清空/恢复、回收站排除与恢复，以及具体颜色和蓝色大类筛选。
- 隔离服务 8081 使用两个普通测试账号和真实本地处理任务；没有发送收费模型调用，没有修改主账号或主衣柜数据。
- ego-browser 实际输入淡蓝色、小圆领，图案回车添加刺绣及细条纹，暂存、选择原图、确认入柜、刷新、动态建议及蓝色大类筛选通过。单值成分和洗护中的标点保留。
- 390 / 768 / 1440px 元信息页面无横向溢出，输入关联明确 label；截图位于忽略的 `.local/open-metadata-check/screenshots/`。

原始 QA 记录位于忽略的 `.local/open-metadata-check/report.json`，测试凭据及数据不纳入 Git。此次验证证明开放值的数据与交互流程可用，不代表新提示词的真实视觉准确率已经验收；颜色和领口准确率仍需真实误判样本对照。
