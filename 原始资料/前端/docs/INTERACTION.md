# 鱼搭首版交互与 API 约定

## 页面与流程

首次登录先设置新密码，之后进入衣柜。日常流程为：从相册选择或拍摄单件照片 → 预览与选择处理方式 → 提交 → 衣物工作台查看真实进度和图片 → 选择展示图并核对信息 → 确认入柜。提交成功后照片和任务保存在后端，可以继续添加其他衣物，也可以离开页面后返回。

| 页面 | 内容 |
| --- | --- |
| `/login` | 受邀账号登录 |
| `/settings` | 首次改密；正常登录后提供密码修改、额度、回收站入口 |
| `/wardrobe` | 已入柜衣物、搜索、组合筛选与分页 |
| `/outfits` | 已保存搭配、搜索、复制与删除 |
| `/outfits/new`、`/outfits/:id` | 4:5 有限画板、衣物选择、调整、保存与 PNG 导出 |
| `/add` | 原生文件选择/拍照入口、预览、处理模式及允许的高级选项 |
| `/pending` | 尚未入柜的照片，区分处理中、待核对和需处理 |
| `/garment/:id` | 原图/结果对照、真实步骤进度、展示图选择及 16 项信息 |
| `/tasks` | 最近 50 个任务、阶段状态、结果入口和取消 |
| `/trash` | 查看删除的衣物并恢复，不提供永久清除 |

## 状态含义

| 衣物状态 | 含义 |
| --- | --- |
| `DRAFT` | 尚未入柜，处理任务可能正在执行，也可能已结束 |
| `ACTIVE` | 用户明确确认入柜 |
| `TRASHED` | 回收站，恢复后返回删除前状态 |

| 任务状态 | 界面行为 |
| --- | --- |
| `QUEUED / RUNNING` | 显示服务端排队或执行步骤，等待返回结果，暂不确认 |
| `CANCEL_REQUESTED` | 等待服务端终止，仍属于活动任务 |
| `SUCCEEDED` | 处理结束，草稿仍需核对入柜 |
| `NEEDS_REVIEW` | 结果需检查，可能有生成图但未生成贴纸 |
| `FAILED` | 显示失败原因并保留已有照片，可主动重试或使用原图核对 |
| `UNKNOWN` | 上游结果待核实，保留历史，不自动再次调用模型 |
| `CANCELLED` | 已取消，保留原图与已完成步骤 |

“仅识别”不会生成新图片；“本地贴纸”由服务端本地算法处理，不调用识图或生图，信息手填。真实任务进度、调用模型与耗时来自后端。没有结果时显示明确占位，真实模式缺图不使用衣物插画冒充生成结果。

## 会话与编辑

全局路由守卫先恢复当前会话。未登录返回登录页；必须改密的账号只进入设置页，共享计数请求也检查此状态。业务 API 返回 `PASSWORD_CHANGE_REQUIRED` 时再次退回改密流程；会话失效返回登录。

所有调用经过 `src/services/api.ts`，同源 Cookie 和 CSRF 令牌由统一层处理。默认真实 API；显式 `VITE_USE_MOCKS=true` 才使用演示数据，演示模式禁止模型提交与重试。

信息选项读取 `/api/recognition/schema`，使用 Ant Design Vue 单选、多选或文本控件。数组保持字段的单值/多值约定，成分及洗护等单值文本保留逗号。人工清空和恢复自动值分别传 `fields` 的空数组及 `resetFields`。

入柜使用同一个确认接口原子保存 revision、展示图、字段修改和恢复自动值。任务活动期间、连接状态未确认或照片明确不满足单件衣物要求时禁止确认。409 冲突保留输入，核对时只保留修改过的字段，未修改字段更新为服务端当前值，用户再主动保存。

活动任务约每 2 秒轮询，失败退避，终态停止。刷新只查询历史状态，不自动再次提交付费任务。确认结果不会把衣物状态当作任务成功，也不会增加已经结束的任务耗时。

## 响应式与组件

使用 Vue 3、TypeScript、Pinia、Vue Router、Ant Design Vue 4；ConfigProvider 和 Ant App 统一按钮、表单、消息与弹窗主题。界面采用浅灰白背景、黑色主操作、蓝色活动标记和中文无衬线字体。

页面提供浅色/深色切换，登录页和登录后的顶栏均可切换，按钮图标表示可切换到的主题。登录页左侧展示项目专属的鱼搭 SVG 插画，并随主题切换对应配色；窄屏登录页隐藏左侧插画以保持表单空间。默认浅色，选择保存在当前浏览器并跨登录生效；切换会同步 Ant Design Vue 控件、全局表面、文字、边框和助手面板配色。登录后顶栏只保留主题、音效及任务入口，页面标题由内容区展示；侧栏资料区提供退出登录操作，不重复显示后端连接状态。穿搭画板保持白色工作底板，导出的 PNG 不随界面主题改变。

1024px 起使用侧栏，账号和退出区域独立保持在侧栏底部；短屏侧栏可滚动。较小屏幕使用四入口底部导航和突出新增入口。主题及退出图标按钮使用组件库的图标插槽，保留 44px 点击区域；主题图标为 20px，不参与按钮内容的收缩。衣物卡片手机两列、平板三列、桌面四列；详情手机上下排列、桌面图片与进度左右排列。首次改密期间仅保留账号及密码设置入口。相册选择采用直接接收点击的原生 file input，支持重新选择同一张照片。

具体后端路由、账号命令及运行方式见同级后端工程 [产品交付文档](../../smart-closet-server/docs/CLOSET_PRODUCT.md)。

助手对话框左上角复用主界面小球的动作、表情、视线和动效设置；手机端隐藏唤起球时，标题图标仍展示当前状态。发送按钮使用 Ant Design Vue 图标插槽，图标在按钮内居中，按钮与单行或多行输入框的垂直中心对齐。

## 穿搭组合台

组合台沿用 Ant Design Vue 的按钮、表单、菜单、抽屉、空状态与反馈。桌面三栏提供衣柜、画板和属性/层级；衣物可从选择器拖到画板指定位置，右键画板衣物或选择器提供前后层级、替换、移除和信息。点击已加入衣物会定位已有元素，拖入已加入衣物会移动到新落点，均不重复添加。替换保留位置、尺寸、角度和层级；重新排版由用户主动执行并可撤销。

编辑界面独立占满视口，以 56px 顶栏保留名称、返回、保存和导出。全局导航留在搭配列表，衣柜和属性两栏可分别收起，“专注画板”可同时收起或恢复。1280px 以下默认收起属性栏，保持画板空间；工具栏提供展开入口。画板、衣柜列表和属性各自滚动，编辑时不滚动整页。

普通滚轮在工作区移动视图；Shift + 滚轮横移；Ctrl/⌘ + 滚轮围绕鼠标所在点缩放，支持 25%–400% 的适应屏幕倍率。空格 + 左键拖动、鼠标中键拖动和手形工具平移视图。“适应屏幕”恢复居中完整画板。缩放与平移只改变视图，不进入穿搭撤销记录、不改变保存数据，也不影响 PNG 导出范围。

手机和平板编辑时隐藏重复的全局导航，以底部“选衣物、调整、单品层级、更多”操作栏为主。选衣物抽屉可连续加入；长按或双击画板衣物打开精调抽屉，缩放锚点扩大触摸范围。双指缩放和平移查看画板，适应屏幕恢复视图；位置、尺寸、角度和层级均提供按钮或数值操作。

桌面快捷键为方向键移动 2px、Shift + 方向键移动 10px、Delete 移除、Ctrl/⌘ + Z 撤销、Ctrl/⌘ + Shift + Z 重做、Ctrl/⌘ + S 保存；表单编辑时不会触发移除或移动。Escape 优先关闭当前菜单/抽屉。

搭配使用真实 `/api/outfits` 接口，按账号和搭配隔离保留本机草稿；刷新或返回列表后再进入可恢复未保存输入，云端版本变化提供重新加载/另存副本。导出为 1080×1350 PNG，仅含画板；图片失败显示重试并阻止缺图导出。查看衣物信息显示最新衣柜信息，保存的图片仅在主动替换时更新。

## 元信息开放值（2026-09-30）

16 项字段结构保持固定，模型和用户可填写新的属性名称。单值使用 Ant Design AutoComplete 建议输入（无建议时为 Input），多值使用 Select tags，输入后按回车添加；清空与恢复自动值语义不变。建议不是限制，服务端返回的新值即使不在常见示例中也完整显示。单值文本中的逗号保持原样。

`GET /api/recognition/schema` 的 options 合并常见示例与本人 ACTIVE 衣物有效值；衣柜筛选从 `GET /api/closet/metadata-options` 获取全部已入柜衣物的实际值，覆盖所有页，不包含草稿、回收站及其他账号。确认后新值可复用，人工修改、清空、恢复及删除随实际衣柜同步。

服务端对少量明确同义词归并（浅蓝/淡蓝色 → 浅蓝色），保留灰蓝色等独立名称。筛选蓝色可匹配浅蓝色、灰蓝色、藏蓝色，选择浅蓝色只匹配该细节值；不对未覆盖名称强制归类。新任务使用 garment-v2 提示词和开放字符串 Schema；已有任务与历史不自动重新识别。

## 贴纸未完成的衔接（2026-09-30）

图片工作台和进度始终区分中间图与最终贴纸。透明检查中断时，进度显示「尚未制作」，步骤轨道停留在处理阶段，正常「确认入柜」不可点击。恢复面板展示检查原因和本地操作：重新抠图（从检查前的图片开始），或者核对有效透明图后继续真正制作贴纸。两种路径均无 AI 调用与额度消耗，不自动重试。未保存信息先暂存，冲突保留输入；新任务约2秒轮询，刷新从后端恢复。

允许明确选择「暂用原图入柜，稍后制作」，对话框说明贴纸未完成；后台仅接受衣物原始上传图作为该备用路径。衣柜卡片、未入柜筛选和详情统一显示贴纸未完成，不被最近的识别任务或 ACTIVE 状态掩盖。完成后展示实际贴纸结果，提供「选用贴纸展示图」；已入柜衣物保存修改，草稿核对后确认入柜。

继续任务的本地耗时单独显示；前次处理记录可展开查看，不将本地短耗时混成原始 AI 的耗时。重新抠图后若仍有结构警告，继续显示待处理状态，不自动冒充贴纸完成。
