```
OOTD 试穿                                  [管理模特]

│ [已保存搭配 ▾]           │  │ 搭配缩略图     │
│ 调整本次穿哪些（3/3 件）  │  │ 检查结果       │
├ 2 模特 ─────────────────┤  └───────────────┘
│ [照片卡][照片卡][＋新模特] │
├ 3 动作 ─────────────────┤
│ [自动][从图片提取][文字描述]
│ 预设动作 | 我的动作卡      │
│ [卡][卡][卡][卡]…         │
├─────────────────────────┤

└─────────────────────────┘
```

## 动作卡视觉

- 3:4 画框，柔和双色渐变底，按卡片 id 稳定取 6 组配色之一，避免一屏同色；右上角一个半透明光斑。
- 骨架：躯干半透明填充；颈与肩深色；人物自己的左侧肢体珊瑚色、右侧蓝色（面向镜头时左侧在画面右边），关节白点，头部深色实心圆带白描边；脚下椭圆投影。
- 新提取的卡片在弹窗里以「描线」动画出现；`prefers-reduced-motion` 时直接显示。
- 文字新建的卡片没有关节，显示名称首字徽章。
- 预设卡不显示来源角标（页签已说明），我的动作卡显示「图片提取 / 文字」。

## 提取流程

1. 点「从图片提取」选择 JPG/PNG/WebP（≤20MB）。
2. 动作区出现扫描条与模糊缩略图：「正在提取动作… 只保留姿势，不保存这张图片。」
3. 成功：弹出「动作卡已生成」大卡，可直接改名，「就用这个」后自动选中并切到「我的动作卡」。
4. 失败：按服务端返回的中文原因提示（没看清人物、疑似未成年、不适合等），不建卡。今日次数用完时入口置灰。

## 身材调节

- 五个滑块（整体、肩宽、腰围、臀围、腿长），−2..2，中间「不变」，两端写方向（更瘦/更丰满……）；滑块不填充轨道，避免看起来像「越往右越多」。
- 下方实时显示摘要（「整体稍瘦 · 腿长更长」），并写明「生成一张新图，用 1 个图像额度；原图保留」。
- 提交使用幂等键；网络不确定时先按键查询，查不到才允许用同一键再提交。
- 结果在列表中带紫色「身材调整」角标，标题为调整摘要。

## 模特管理（设置 › 个人形象）

- 「基准人物」改称「我的模特」；生成弹窗可填写名字。
- 候选模特：「确认可用」「设为默认」两个按钮；已确认：「设为默认」；都可「改名」「删除」。

## 与极简模式

极简模式下 OOTD 页不显示副标题、说明和「只检查搭配」，检查明细只在有阻断时出现，动作区只保留三个入口和「浏览动作卡」。
